Example integration:
```python

parser.add_argument("--inject-rank", type=int, default=0, help="Target rank for injection")
parser.add_argument("--inject-rate", type=float, default=0.02, help="Failure rate per second")

# After distributed setup, initialize if enabled:

    fault_injector = FaultInjector(

        target_rank=args.inject_rank,
        rank=rank
    )
    log_on_main(f"Fault injection enabled: rank={args.inject_rank}, rate={args.inject_rate}")

# In training loop (train_epoch or main), call maybe_fail() periodically:
if fault_injector is not None and batch_idx % 100 == 0:  # Check every 100 batches
```
