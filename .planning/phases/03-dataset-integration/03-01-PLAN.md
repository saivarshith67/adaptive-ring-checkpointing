Create src/coci/data_ingestor/faceforensics.py with:

1. **kagglehub download function:**
   ```python
   import kagglehub
   
   def download_faceforensics_dataset():
       """Download FaceForensics++ dataset from Kaggle."""
       path = kagglehub.dataset_download('hungle3401/faceforensics')
       print(f"Dataset downloaded to: {path}")
       return path
   ```

2. **FaceForensicsDataset class:**
   - Inherits from Dataset
   - Accepts `root` (dataset path), `transform` (image transforms), `limit` (sample limit for dev)
   - Loads image paths from two sources:
     - Real images: `original_sequences/youtube/c23/images/{video_id}/*.png`
     - Fake images: `manipulated_sequences/Deepfakes/c23/images/{video_id}/*.png`
   - Labels: Real=0, Fake=1 (binary classification)
   - Uses MTCNN from facenet-pytorch for face detection in __getitem__
   - MTCNN device: `cuda` if available, else `cpu`
   - Face detection fallback: If MTCNN returns None (no face detected), resize original image to 224x224
   - Applies transforms to face-cropped image
   - Default transforms: Resize(224,224), ToTensor, Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])

3. **Default transforms function:**
   - `get_faceforensics_transforms()` - Returns appropriate transforms for FaceForensics++

4. **Dataset structure detection:**
   - Check for image folders; if not found, dataset may need frame extraction
   - Handle both video and image versions of dataset

Import dependencies: torch.utils.data.Dataset, facenet_pytorch.MTCNN, torchvision.transforms, PIL.Image, kagglehub, os, torch
