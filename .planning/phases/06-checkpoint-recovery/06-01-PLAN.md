<task type="auto">
  <name>Task 2: Verify DistributedSampler state management</name>
  <files>scripts/train_faceforensics.py</files>
  <action>
Verify that DistributedSampler handles epoch synchronization correctly on resume:

1. **Epoch synchronization**: `train_sampler.set_epoch(epoch)` is called at start of each epoch
2. **Resume behavior**: After checkpoint load, the next epoch should use the correct epoch value
3. **No data leakage**: Resume should not repeat samples already seen

The key issue: when resuming from epoch 5, the next epoch should be 6, not 0. This requires:
- `start_epoch` from checkpoint to be the NEXT epoch to train (not the last completed)
- Or add +1 when passing to range()

Current code uses `range(start_epoch, args.epochs)` which should be correct. Verify:
```python
start_epoch = checkpoint_manager.load_latest(model, optimizer, device)
for epoch in range(start_epoch, args.epochs):
    # epoch starts at start_epoch, not 0
    sampler.set_epoch(epoch)
```
