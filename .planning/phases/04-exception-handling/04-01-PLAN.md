Wrap the training loop with try/except for fault detection and graceful handling. When an exception occurs, all ranks synchronize via barrier() before rank 0 saves an emergency checkpoint. The exception then propagates to trigger torchrun auto-restart.
</objective>

  <name>Task 1: Add exception handling wrapper to training loop</name>
  <files>scripts/train_faceforensics.py</files>
  <action>
Wrap the training loop (lines 900-964) with a try/except block that:

1. Wraps the entire epoch iteration (for loop body) in try/except
2. Catches generic `Exception` (not just RuntimeError - covers all failure modes)
3. On exception:
   - First: Call `barrier()` to synchronize all ranks before checkpoint save
   - Second: Call `checkpoint_manager.save()` for emergency checkpoint
   - Third: Log error message on main rank with exception details
   - Fourth: Re-raise the exception to trigger torchrun auto-restart

The structure should be:
```python
for epoch in range(start_epoch, args.epochs):
    try:
        # [Current epoch code: train, validate, checkpoint save]
    except Exception as e:
        # Barrier sync first - prevents rank 0 from saving while others are still running
        barrier()
        
        # Emergency checkpoint save
        checkpoint_manager.save(model, optimizer, epoch, val_loss, metric=val_acc)
        
        # Log error
        log_on_main(f"Training failed at epoch {epoch}: {e}")
        log_on_main("Saving emergency checkpoint and exiting...")
        
        # Re-raise to trigger torchrun restart
        raise
```

Important: The barrier() call MUST come before the save() call to ensure all ranks are synchronized. The re-raise MUST be outside the if block so it always propagates.
